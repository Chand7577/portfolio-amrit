# Amrit Chand — Portfolio

Personal portfolio and engineering showcase of **Amrit Chand**, Full-Stack Developer specializing in React, Next.js, TypeScript, and modern web architectures.

🔗 **Live:** [amritchand.dev](https://amritchand.dev)

---

## ⚡ Tech Stack

- **Framework:** Next.js (App Router), React 19, TypeScript
- **Styling:** Tailwind CSS, CSS View Transitions
- **Animation & 3D:** Motion, Three.js, Lenis Smooth Scroll
- **Forms & Backend:** Web3Forms, Zod, Next.js API Routes

---

## ✨ Highlights

- **Cinematic Hero:** Layered portrait with left-to-right velocity typography masking.
- **Circular Work Carousel:** Interactive 3D carousel showcasing live client builds.
- **Interactive UI:** PixelCard pricing grid, tabbed category FAQ accordion, and 3D Hyperspeed background.
- **Theme Ripple:** Dark/Light mode toggle with full-page circular expanding wave.
- **Web3Forms Contact:** Validated contact pipeline with anti-spam protection.

---

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/Chand7577/portfolio-amrit.git
cd portfolio-amrit

# Install dependencies
npm install

# Start local dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
